# AdScale

Архитектура постепенного перехода рекламной платформы от монолита к сервисам. Сначала выделяются Bidding и прием событий, затем остальные сервисы. Новые сервисы пишутся на Go; существующие компоненты сохраняются до переноса их функций.

| Раздел | Содержание |
|---|---|
| [Task1](Task1/README.md) | Диагностика, требования, промежуточная и целевая архитектура, ADR |
| [Task2](Task2/README.md) | Bidding, OpenRTB, Gateway и надежность |
| [Task3](Task3/README.md) | Хранилища, кеш, Kafka, масштабирование и восстановление |
