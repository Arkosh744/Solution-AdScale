# API Gateway

Выбран Envoy Proxy перед монолитом и новыми сервисами. Он объединяет маршрутизацию, аутентификацию, ограничение запросов и мониторинг; бизнес-логика остается в сервисах.

| Вариант | Ограничение | Почему у нас нельзя проще |
|---|---|---|
| Прямой доступ к Bidding | Политики повторяются в каждом адаптере | Gateway нужен и для перехода между старым и новым путями |
| Envoy | Требует сопровождения конфигурации | Выбран: TLS, лимиты, проверки upstream и тайм-ауты доступны штатно |
| Коммерческая API-платформа или service mesh | Дополнительная эксплуатация и стоимость | Для заданных маршрутов достаточно самостоятельного proxy |

## Маршруты и доступ

| Маршрут | Получатель | Защита |
|---|---|---|
| `/openrtb2/auction` | Bidding | mTLS, лимит партнера, общий дедлайн |
| `/v1/partners/*/events` | Statistics | mTLS и удостоверенный `partner_id` |
| `/api/*` | Кабинет и API сервисов | Пользовательская авторизация, проверка рекламодателя |
| health/metrics/admin | Внутренняя сеть | Недоступны из интернета |

Сертификат проверяется по доверенному CA и идентичности партнера. Gateway удаляет подставленные клиентом служебные заголовки и передает удостоверенный `partner_id`.

Statistics отвечает `202` после устойчивого сохранения события; это подтверждение приема, а не списания. Принадлежность резерва партнеру и сумму проверяет Finance при обработке события. Отдельная прикладная подпись уведомления не используется.

На каждую ставку нет обращения к внешнему сервису авторизации. Тела запросов, токены и персональные данные не попадают в обычный access log.

## Ограничения

Номинал нового партнера составляет 3 000 RPS. Начальная конфигурация использует два Gateway по 3 000 RPS каждый; при отказе одного сохраняется номинал.

Лимит локальный: вместе Gateway допускают до 6 000 RPS, а не строгие глобальные 3 000. Поэтому весь первый этап проверяется также на 21 000 RPS с учетом старых 15 000. Перед добавлением Gateway пересчитываются суммарный допуск и мощность.

Тело RTB ограничено 64 КиБ. Очередь и число соединений ограничены; перегрузка возвращает 429/503 вместо неограниченного ожидания.

События имеют отдельные пулы и квоты, чтобы всплеск ставок не блокировал финансовые уведомления. Таймер и запрет повторов заданы в [бюджете времени](interaction.md).

## Отказы и наблюдаемость

Envoy исключает неработающие upstream по health checks и ошибкам соединения. Circuit Breaker ограничивает соединения и очередь, но не определяет финансовый результат запроса.

Метрики: полный ответ, время upstream, 4xx/5xx, тайм-ауты, отказы доступа и квот. Для сравнения версий используются партнер и маршрут; request ID не становится меткой метрики.

Проверить отказ одного Gateway, недоступность Bidding, медленное тело и поддельные служебные заголовки. Ограничение нового партнера не останавливает текущих клиентов.
