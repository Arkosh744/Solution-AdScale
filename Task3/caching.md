# Кеширование

Bidding держит подготовленные кампании в памяти. Redis распространяет версии и помогает прогреву; обращения к нему нет на каждую ставку.

## Данные и TTL

| Данные | Где | Начальное ограничение |
|---|---|---|
| Неизменяемая версия кампании | Redis | TTL 5 минут |
| Актуальность активной кампании | Campaign и локальная копия Bidding | Не более 5 секунд |
| Индекс таргетинга | Память Bidding | До смены версии или истечения актуальности |
| Бюджет для отображения в кабинете | Redis | TTL 5 секунд, не разрешение на расход |
| Кешированная цена | Память Bidding | До 30 секунд, только с актуальной кампанией |

Физические пять минут хранения не разрешают торговать по устаревшей кампании. Логический срок актуальности задает Campaign; недоступность источника его не продлевает.

Допустимая задержка отмены кампании принята равной пяти секундам. Такое окно нужно согласовать с бизнесом перед подключением партнера.

## Обновление

1. Campaign меняет состояние и увеличивает версию в транзакции с outbox.
2. Фоновый обработчик публикует изменение, обновляет Redis и сообщает новую версию Bidding.
3. Bidding загружает данные, строит индекс и атомарно заменяет локальную копию.

Старое событие не заменяет новую версию. Дополнительно Bidding сверяет версию с источником раз в секунду; при пропуске изменений загружается полный снимок.

Копия из отстающей реплики не считается подтверждением свежести. При истечении срока кампания исключается из новых ставок.

## Прогрев и отказы

Новый экземпляр принимает трафик после загрузки кампаний и проверки доступности своего учета резервов. Прогрев не создает новые бюджетные лимиты.

Загрузка ограничена по параллелизму; одинаковые промахи объединяются, TTL получает небольшой случайный разброс. Это предотвращает одновременный поток запросов в Campaign после потери Redis.

При отказе Redis действует еще актуальная локальная копия. После ее срока положительные ставки прекращаются, а не переходят на массовое синхронное чтение БД.

Резервы и доступный денежный остаток проверяются в PostgreSQL Bidding. Сброс кеша не возвращает потраченный бюджет.
